### Task Manager REST API

Task Manager API to manage todo list.

Concepts used:

 Spring Boot
 
 Mysql
 
 Spring data JPA
 
 Spring docs
 
 Spring Validation
 
 DTO model
 
 Model Mapper
 
 REST API
 
 Lombok
 
 Developed Web services for Task Manger App which handles Create,Read,Delete and Update operations on User and Todo repositories.
